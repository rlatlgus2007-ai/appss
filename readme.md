# 🎓 대학 생활 데이터 대시보드 (Campus Life Dashboard)

스트림릿(Streamlit)을 활용하여 대학생들의 생활 습관, 학교 생활 만족도, 그리고 한줄 의견을 분석하고 시각화해 주는 웹 대시보드 애플리케이션입니다.

## 🚀 주요 기능
- **데이터 업로드 및 자동 전처리**: `campus_life.csv` 파일을 업로드하면 결측치를 제거하고, 띄어쓰기 등 발생할 수 있는 오류를 자동으로 보정합니다.
- **학과별 맞춤 필터링**: '전체' 또는 특정 학과를 선택하여 맞춤형 데이터를 분석할 수 있습니다.
- **다양한 데이터 시각화**:
  - 📊 **생활습관 비교**: 수면시간, 공부시간, 스마트폰 사용시간 평균을 막대그래프로 비교합니다.
  - 📈 **상관관계 분석**: 공부시간과 만족도 간의 관계를 산점도로 보여줍니다.
- **💬 텍스트 및 감성 분석 (한줄 의견)**:
  - 가장 자주 등장하는 키워드 Top 10을 추출하여 시각화합니다.
  - 지정된 키워드를 바탕으로 긍정/부정 단어의 등장 횟수를 카운트하여 보여줍니다.

## 🛠️ 사용된 기술 (Tech Stack)
- Python 3.x
- [Streamlit](https://streamlit.io/) (웹 프레임워크 및 UI)
- Pandas (데이터 분석 및 전처리)
- Matplotlib & Seaborn (데이터 시각화)

## 📥 설치 및 실행 방법

1. **저장소 클론(Clone)**
   ```bash
   git clone https://github.com/본인아이디/레포지토리이름.git
   cd 레포지토리이름
   ```

2. **필요한 라이브러리 설치**
   프로젝트 폴더 내에서 아래 명령어를 실행하여 필수 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```

3. **앱 실행**
   아래 명령어를 통해 Streamlit 대시보드를 실행합니다. (파이썬 파일 이름이 `app.py`인 경우)
   ```bash
   streamlit run app.py
   ```

## 📊 CSV 데이터 양식 안내
원활한 분석을 위해 업로드하는 CSV 파일에는 가급적 다음의 열(Column)이 포함되어 있어야 합니다. (열 이름의 띄어쓰기는 자동 제거됩니다.)
- `학과`: 필터링에 사용됩니다.
- `만족도`, `수면시간`, `공부시간`, `스마트폰사용시간`: 숫자형 데이터여야 합니다.
- `한줄의견`: 텍스트 및 감성 분석에 사용됩니다.
